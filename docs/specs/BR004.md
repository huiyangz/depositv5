# BR004 检查交易机构和基本户开户机构互斥性

## 目标与范围

本 Spec 定义存款业务组件（deposit，包名 com.dcits.depsit）中断言类规则 BR004 的判定行为：依据交易机构号与账户开立行行号（基本户的开户机构行号）的相等性、账户属性是否为"11002-一般存款账户"，输出执行结果"通过"或"不通过"。

范围：

- 规则判定的完整条件分支（不通过路径与通过路径）。
- 规则的输入字段、类型、必填性及输出契约。
- 规则的工程落点（类路径、方法名、返回类型映射）与无状态约束。

不在范围内：

- 交易机构号、账户开立行行号、账户属性数据的来源与维护（三者均为规则输入，由调用方提供，规则本身不查询数据）。
- 输入为空（null）时的行为——正式需求未定义，本 Spec 不约定（见"验收范围与明确不覆盖的事项"）。
- 一般存款账户开立的其他业务校验，以及本规则在交易或步骤中的调用编排与结果消费方式。

## Requirements

### Requirement: REQ-001 交易机构与基本户开户机构互斥性判定
来源：docs/requirements/BR004.md「规则描述」（原文：若{交易机构号}等于{账户开立行行号}且{账户属性}为"11002-一般存款账户"则返回执行结果为"不通过"，否则返回执行结果为"通过"）

系统 SHALL 基于三个必填输入 tranBranch（交易机构号）、acctNatureNo（账户属性）、acctBranch（账户开立行行号，指基本户的开户机构行号）判定互斥性并返回执行结果：

- 当 tranBranch 等于 acctBranch（同一内部机构编号）且 acctNatureNo 为 11002-一般存款账户（AcctNatureNo.VALUE_11002）时，系统 MUST 返回执行结果"不通过"（execute 返回 false）。
- 其余全部合法输入组合（机构不相等，或账户属性不为 11002-一般存款账户，或两者同时不满足），系统 MUST 返回执行结果"通过"（execute 返回 true）。

判定 MUST 为无状态纯计算：不访问数据库或外部接口，不发起任何业务服务调用，不产生状态变更或副作用。

#### Scenario: REQ-001-S01 机构相同且账户属性为一般存款账户，返回不通过
- **GIVEN** acctNatureNo 为 AcctNatureNo.VALUE_11002（"11002"-一般存款账户），tranBranch 与 acctBranch 为同一内部机构（示例：均为 TranBranch.VALUE_351155，"351155"）
- **WHEN** 以 tranBranch=TranBranch.VALUE_351155、acctNatureNo=AcctNatureNo.VALUE_11002、acctBranch=TranBranch.VALUE_351155 调用规则 execute
- **THEN** 返回执行结果为"不通过"，即 execute 返回 false；不产生任何状态变更或外部副作用

#### Scenario: REQ-001-S02 机构相同但账户属性不为一般存款账户，返回通过
- **GIVEN** tranBranch 与 acctBranch 为同一内部机构（示例：均为 TranBranch.VALUE_351155），acctNatureNo 为 11002 以外的合法账户属性（示例：AcctNatureNo.VALUE_11001，"11001"-基本存款账户）
- **WHEN** 以 tranBranch=TranBranch.VALUE_351155、acctNatureNo=AcctNatureNo.VALUE_11001、acctBranch=TranBranch.VALUE_351155 调用规则 execute
- **THEN** 返回执行结果为"通过"，即 execute 返回 true

#### Scenario: REQ-001-S03 机构不同且账户属性为一般存款账户，返回通过
- **GIVEN** acctNatureNo 为 AcctNatureNo.VALUE_11002（"11002"-一般存款账户），tranBranch 与 acctBranch 为不同内部机构（示例：tranBranch=TranBranch.VALUE_351155（"351155"），acctBranch=TranBranch.VALUE_351156（"351156"））
- **WHEN** 以 tranBranch=TranBranch.VALUE_351155、acctNatureNo=AcctNatureNo.VALUE_11002、acctBranch=TranBranch.VALUE_351156 调用规则 execute
- **THEN** 返回执行结果为"通过"，即 execute 返回 true

#### Scenario: REQ-001-S04 机构不同且账户属性不为一般存款账户，返回通过
- **GIVEN** tranBranch 与 acctBranch 为不同内部机构（示例：tranBranch=TranBranch.VALUE_351155，acctBranch=TranBranch.VALUE_351156），acctNatureNo 为 11002 以外的合法账户属性（示例：AcctNatureNo.VALUE_11001）
- **WHEN** 以 tranBranch=TranBranch.VALUE_351155、acctNatureNo=AcctNatureNo.VALUE_11001、acctBranch=TranBranch.VALUE_351156 调用规则 execute
- **THEN** 返回执行结果为"通过"，即 execute 返回 true

## 验收范围与明确不覆盖的事项

验收范围（以本 Spec 场景为测试设计依据，非已生成的测试或测试结果）：

- REQ-001-S01 至 S04 的判定结果断言（含 execute 返回值与执行结果的映射）。
- execute 输入参数的名称、顺序与类型；boolean 返回映射（true=通过 / false=不通过）。
- 规则无副作用：不访问数据库、外部接口或业务 Service，无状态变更。

明确不覆盖：

- 输入为 null 的行为：需求将三字段标记为必填但未定义空值时的结果，本 Spec 不约定此类输入的返回值或异常，测试不应将其作为业务断言场景。
- 机构编号真实性、有效性核验：取值域由 TranBranch / AcctNatureNo 枚举限定，规则不做数据库核验。
- 一般存款账户背景下的其他开户校验（如开户数量、资质），需求未涉及。
- 本规则被交易或步骤调用的编排方式、调用时机与结果消费方式。
- 需求未要求的重试、异常处理、默认值兜底。
