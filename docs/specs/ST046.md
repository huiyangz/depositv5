# ST046 检查币种

## 目标与范围

本任务为存款业务组件的交易执行步骤「检查币种」。步骤目标：依据产品配置校验账户币种是否在产品允许的币种范围内，检查结果通过 StepResult 状态表达，不产出业务输出字段。

范围内：

- 依据输入 {产品编号}（prodNo）与 {参数KEY值}（attrKey）调用业务组件《产品管理》业务功能《查询产品信息》，取得产品 $币种$ 集合；
- 判断输入 {币种}（ccy）是否包含于产品币种集合，并按「通过 / ER0023」映射 StepResult。

不在范围内：

- 《查询产品信息》功能内部的实现与契约细节（属产品管理组件）；
- 产品定义表（MB_PROD_DEFINE）属性的登记与维护；
- 《查询产品信息》调用失败或异常时的处理策略（正式需求未规定，本 Spec 不设默认行为）；
- 失败时 errorMessage 文案内容（正式需求未约定）。

## 正式需求来源

- 本任务业务事实来源：`docs/requirements/ST046.md`（正式需求），引用条目：「步骤描述」第 1、2 条、「输入」、「输出」、「相关枚举」、「补充说明」。
- 本步骤无按任务编号关联的其他正式 Spec；外部依赖《产品管理·查询产品信息》以需求正文描述的调用用途为准，其技术形状经工程接口 `ExternalTaskClient.queryProductInfo(String prodNo, String attrKey)` 确认。

## 输入、输出及依赖契约

### 输入（均必填）

| 字段 | 类型 | 必填 | 来源实体 | 说明 |
|------|------|------|----------|------|
| ccy | com.dcits.depsit.enums.Ccy | 是 | — | 币种（{币种,输入数据-币种}，取值来源于代码[货币币种]） |
| prodNo | java.lang.String | 是 | 产品定义表（MB_PROD_DEFINE） | 产品编号 |
| attrKey | java.lang.String | 是 | 产品定义表（MB_PROD_DEFINE） | 参数KEY值 |
| attrValue | java.lang.String | 是 | 产品定义表（MB_PROD_DEFINE） | 属性值 |

attrValue 说明：正式需求将其声明为必填输入，但「步骤描述」与「补充说明-外部调用」均未引用该字段；《查询产品信息》调用入参仅含 prodNo、attrKey（工程接口已确认）。本 Spec 按需求原样保留该输入声明，不为其规定用途。

### 输出

无业务输出字段，步骤结果完全由 StepResult 状态字段表达（状态字段由 StepResult 继承，不在业务输出中重复声明）：

| 业务结果 | StepResult 映射 |
|----------|-----------------|
| [检查结果]"通过" | succeed=true，errorCode 为空，errorMessage 为空 |
| [错误码]"ER0023" | succeed=false，errorCode="ER0023"；errorMessage 内容需求未约定，不作约束 |

### 依赖调用

- 业务组件《产品管理》业务功能《查询产品信息》：入参 {产品编号}（prodNo）、{参数KEY值}（attrKey）；本步骤消费其返回结果中的 $币种$ 集合（工程接口 `ExternalTaskClient.queryProductInfo` 返回 `QueryProductInfoResult.ccyList`，元素为币种代码字符串）。

### 枚举与比较语义

- {币种} 对应枚举 `com.dcits.depsit.enums.Ccy`（货币币种），已确认取值：AUD、CAD、CHF、CNY、EUR、GBP、HKD、JPY、KRW、RUB、SGD、USD，枚举代码值与名称一致（如 CNY→"CNY"）。
- 包含性判断基于币种代码字符串：ccy 取其代码值（getValue()）与集合元素比较。

## Requirements

### Requirement: REQ-001 获取产品币种集合
来源：`docs/requirements/ST046.md`「步骤描述」第 1 条；「补充说明-外部调用」。
系统 SHALL 依据输入 {产品编号}（prodNo）与 {参数KEY值}（attrKey）调用业务组件《产品管理》业务功能《查询产品信息》恰好一次，并从返回结果中取得产品 $币种$ 集合（ccyList），供币种范围检查使用；该调用先于包含性检查执行。

#### Scenario: REQ-001-S01 按产品编号与参数KEY取得币种集合
- **GIVEN** 产品 P0001 在参数KEY CCY（示例值；实际KEY由产品定义登记决定，需求未规定固定常量）下可查询到产品信息，其币种集合为 ["CNY","USD"]（示例数据）
- **WHEN** 以 prodNo="P0001"、attrKey="CCY" 执行本步骤（ccy、attrValue 按输入契约同时传入，本场景不依赖其取值）
- **THEN** 《查询产品信息》被调用恰好一次且入参为 prodNo="P0001"、attrKey="CCY"，步骤取得币种集合 ["CNY","USD"] 并用于后续包含性检查

### Requirement: REQ-002 检查币种是否在产品配置范围内并映射步骤结果
来源：`docs/requirements/ST046.md`「步骤描述」第 2 条；「输出」。
系统 SHALL 判断产品币种集合是否包含输入 {币种}（ccy 的币种代码值）：包含时 [检查结果] 为"通过"，映射 StepResult succeed=true、errorCode 与 errorMessage 均为空；不包含时返回 [错误码] "ER0023"，映射 succeed=false、errorCode="ER0023"。除 StepResult 继承的状态字段外，系统 SHALL NOT 另行产出业务输出字段。

#### Scenario: REQ-002-S01 币种在集合内——检查通过
- **GIVEN** 取得的产品币种集合为 ["CNY","USD"]（示例数据）
- **WHEN** 输入 ccy=CNY（代码值 "CNY"）
- **THEN** succeed=true，errorCode 为空，errorMessage 为空，无业务输出字段

#### Scenario: REQ-002-S02 币种不在集合内——返回 ER0023
- **GIVEN** 取得的产品币种集合为 ["CNY","USD"]（示例数据）
- **WHEN** 输入 ccy=JPY（代码值 "JPY"）
- **THEN** succeed=false，errorCode="ER0023"，无业务输出字段

#### Scenario: REQ-002-S03 边界——产品币种集合为空
- **GIVEN** 《查询产品信息》返回的产品币种集合为空集合
- **WHEN** 输入 ccy=CNY
- **THEN** 空集合不包含任何币种，落入「否则」分支：succeed=false，errorCode="ER0023"
