# DT001 根据核准类型设置账户状态

## 目标与范围

本任务为决策类规则：依据账户属性、对公存款账户用途、境内境外标志、企业标志四个输入，判定并返回对公存款账户的账户状态（新建 / 预开户 / 无）。

- 范围内：上表四输入到账户状态输出的全部判定分支、输入输出字段契约、业务标签与枚举取值映射。
- 不在范围内：账户状态判定之外的任何开户处理（如黑名单、限额、检查限制、维护限制等组件行为）、账户状态在 RB_BUS_ACCT 的落库及后续流程、枚举类本身的定义与维护。

## 正式需求来源

- `docs/requirements/DT001.md`（任务编号 DT001，版本 1，规则类型：决策类）
  - 「规则描述」第 1 条（含 a–d）、第 2 条、第 3.1 条（含 a–d）、第 3.2 条（含为空）、第 4 条（含 a–d）、第 5 条（含 a–d）、第 6 条
  - 「输入」表（4 个字段）、「输出」表（acctStatus 及取值映射）、「相关枚举」、「补充说明」（枚举类绑定）
- 关联正式 Spec：无。本规则为独立决策规则，不调用其他组件或服务，`docs/specs/` 下无本任务依赖的已合并 Spec。

## 输入、输出及依赖契约

### 输入

| 字段名 | 类型 | 必填性 | 说明 |
|--------|------|--------|------|
| rbBusAcctPurpose | com.dcits.depsit.enums.RbBusAcctPurpose | 非必填 | 对公存款账户用途，可为空 |
| acctNatureNo | com.dcits.depsit.enums.AcctNatureNo | 必填 | 账户属性 |
| corporationFlag | java.lang.String | 必填 | 企业标志，按需求文本以"是"/"否"判定 |
| inlandOffshore | java.lang.String | 必填 | 境内境外标志，按需求文本以"境内"/"境外"判定 |

境内境外标志、企业标志为 String 类型，需求未绑定枚举或代码表，本 Spec 以需求文本取值（"境内"/"境外"、"是"/"否"）作为判定常量；需求未定义二者为其他取值时的行为，本 Spec 不约束。

## Requirements

### Requirement: REQ-001 账户属性为基本户的账户状态判定

来源：`docs/requirements/DT001.md`「规则描述」第 1 条 a–d
系统 SHALL 在{账户属性}为"基本户"时，按{境内境外标志}与{企业标志}的组合输出[账户状态]：境内+是→"新建"；境内+否→"预开户"；境外+是→"预开户"；境外+否→"新建"。本分支不引用{账户用途}。

#### Scenario: REQ-001-S01 基本户·境内·企业→新建

- **GIVEN** acctNatureNo 为"基本户"（AcctNatureNo.VALUE_11001，"11001"），inlandOffshore 为"境内"，corporationFlag 为"是"
- **WHEN** 执行 DT001 规则判定
- **THEN** 输出 acctStatus 为"新建"，取值 AcctStatus.N（"N"）

#### Scenario: REQ-001-S02 基本户·境内·非企业→预开户

- **GIVEN** acctNatureNo 为"基本户"（"11001"），inlandOffshore 为"境内"，corporationFlag 为"否"
- **WHEN** 执行 DT001 规则判定
- **THEN** 输出 acctStatus 为"预开户"，取值 AcctStatus.I（"I"）

#### Scenario: REQ-001-S03 基本户·境外·企业→预开户

- **GIVEN** acctNatureNo 为"基本户"（"11001"），inlandOffshore 为"境外"，corporationFlag 为"是"
- **WHEN** 执行 DT001 规则判定
- **THEN** 输出 acctStatus 为"预开户"，取值 AcctStatus.I（"I"）

#### Scenario: REQ-001-S04 基本户·境外·非企业→新建

- **GIVEN** acctNatureNo 为"基本户"（"11001"），inlandOffshore 为"境外"，corporationFlag 为"否"
