# BR006 设置自贸区种类

## 目标与范围

本任务为存款业务组件（deposit-service，包名 com.dcits.depsit）内的规则，规则类型：断言类。目标：依据客户身份类输入（对私客户标志、税收居民标识、客户类型、境内境外标志），判定并返回[自贸区种类]，即对公存款账户主表（RB_BUS_ACCT）的账户属性字段 acctNatureNo，取值为五个自由贸易账户种类之一。

范围内：

- 规则描述 a–e 共五个条件分支的判定条件与输出取值映射；
- 不满足任何条件分支时输出为空的行为；
- 输入、输出字段契约及相关枚举绑定。

不在范围内的事项见"验收范围与明确不覆盖的事项"。

## 正式需求来源

- `docs/requirements/BR006.md`（任务编号 BR006，系统编号 SYS-1062），构成：规则类型、规则描述 a–e、输入表、输出表、相关枚举、补充说明。
- 本任务无关联的其他正式 Spec：仓库 `docs/specs/` 下不存在与本任务编号明确关联的已合并 Spec；需求中无组件内步骤调用补充说明，无平台服务依赖。

## 输入、输出及依赖契约

### 输入（全部必填；来源实体不适用，取自规则入参）

| 字段名 | 类型 | 说明 | 参与判定的取值（按代码值匹配） |
|--------|------|------|--------------------------------|
| isIndividual | java.lang.String | 对私客户标志 | "Y"（Y-个人） |
| taxResidentFlag | com.dcits.depsit.enums.TaxResidentFlag | 税收居民标识 | VALUE_1（"1"-中国税收居民）、VALUE_2（"2"-非中国税收居民）、VALUE_3（"3"-既是中国税收居民又是其他国家（地区）税收居民） |
| clientType | com.dcits.depsit.enums.ClientType | 客户类型 | VALUE_100（"100"-个人）、VALUE_200（"200"-对公）、VALUE_300（"300"-同业） |
| inlandOffshore | java.lang.String | 境内境外标志 | "Y"（Y-境内）、"N"（N-境外） |

匹配口径：枚举字段按枚举代码值（value）比较；String 字段按字面值比较。空值语义：四个输入均为必填，空值输入的处理需求未定义，由上游保证（见不覆盖事项）。

### 输出

| 字段名 | 契约类型 | 必填性 | 归属 | 取值映射 |
|--------|----------|--------|------|----------|
| acctNatureNo | com.dcits.depsit.enums.AcctNatureNo | 非必填 | 对公存款账户主表（RB_BUS_ACCT），对应实体字段 RbBusAcct.acctNatureNo（存储类型 String，存枚举代码值） | FTI-区内个人自由贸易账户 → VALUE_3605（"3605"）；FTF-区内境外个人自由贸易账户 → VALUE_3606（"3606"）；FTE-区内机构自由贸易账户 → VALUE_3603（"3603"）；FTN-境外机构自由贸易账户 → VALUE_3604（"3604"）；FTU-同业机构自由贸易账户 → VALUE_3607（"3607"） |

"非必填"的含义：仅当规则描述 a–e 任一条件成立时输出取对应值；条件均不成立时输出为空（见 REQ-006）。

### 枚举与实现核对结论

- 三个枚举类均已存在于 `deposit-common/src/main/java/com/dcits/depsit/enums/`，需求引用的代码值全部存在，输出映射的五个代码值（3603/3604/3605/3606/3607）在 AcctNatureNo 中均已定义。
- 标签同义差异（判定以代码值为准，不构成冲突）：需求"2-非中国税收居民"对应 TaxResidentFlag.VALUE_2，枚举注释为"非居民"，代码均为"2"；需求"200-对公"对应 ClientType.VALUE_200，枚举注释为"公司"；需求"300-同业"对应 ClientType.VALUE_300，枚举注释为"金融机构"，代码均一致。

### 分支互斥性与优先级

在客户身份一致的输入下（对私客户标志"Y"对应客户类型"100-个人"，对公/同业客户对私客户标志非"Y"），五个条件分支互斥：分支 a 与 b 的税收居民标识条件（属于{1,3} 与 等于 2）互斥；分支 a/b 与 c/d/e 的客户身份条件互斥；分支 c 与 d 的境内境外标志互斥。需求未定义规则间优先级，一致输入下也无需优先级。需求未定义客户身份相互矛盾的输入（如对私客户标志"Y"且客户类型"200-对公"）的判定结果，本 Spec 不增设（见不覆盖事项）。

### 依赖调用

无平台服务依赖，无组件内步骤调用。

## Requirements

### Requirement: REQ-001 个人客户判定为区内个人自由贸易账户（FTI）
来源：docs/requirements/BR006.md 规则描述 a
系统 SHALL 在 isIndividual 等于 "Y"（Y-个人）且 taxResidentFlag 为 VALUE_1（"1"-中国税收居民）或 VALUE_3（"3"-既是中国税收居民又是其他国家（地区）税收居民）时，返回 acctNatureNo = AcctNatureNo.VALUE_3605（"3605"，FTI-区内个人自由贸易账户）。本分支 SHALL 仅评估 isIndividual 与 taxResidentFlag，clientType 与 inlandOffshore 取值不影响判定结果。

#### Scenario: REQ-001-S01 个人中国税收居民判定为 FTI
- **GIVEN** isIndividual = "Y"，taxResidentFlag = TaxResidentFlag.VALUE_1（"1"），clientType = ClientType.VALUE_100（示例值，本分支不评估），inlandOffshore = "Y"（示例值，本分支不评估）
- **WHEN** 执行规则 BR006
- **THEN** 返回 acctNatureNo = AcctNatureNo.VALUE_3605（代码值 "3605"，FTI-区内个人自由贸易账户）

#### Scenario: REQ-001-S02 个人双重税收居民判定为 FTI
- **GIVEN** isIndividual = "Y"，taxResidentFlag = TaxResidentFlag.VALUE_3（"3"），clientType = ClientType.VALUE_100（示例值，本分支不评估），inlandOffshore = "N"（示例值，本分支不评估）
- **WHEN** 执行规则 BR006
- **THEN** 返回 acctNatureNo = AcctNatureNo.VALUE_3605（代码值 "3605"，FTI-区内个人自由贸易账户）

### Requirement: REQ-002 境外个人客户判定为区内境外个人自由贸易账户（FTF）
来源：docs/requirements/BR006.md 规则描述 b
系统 SHALL 在 clientType 等于 ClientType.VALUE_100（"100"-个人）且 taxResidentFlag 等于 VALUE_2（"2"-非中国税收居民）时，返回 acctNatureNo = AcctNatureNo.VALUE_3606（"3606"，FTF-区内境外个人自由贸易账户）。本分支 SHALL 仅评估 clientType 与 taxResidentFlag，isIndividual 与 inlandOffshore 取值不影响判定结果。

#### Scenario: REQ-002-S01 个人非中国税收居民判定为 FTF
- **GIVEN** clientType = ClientType.VALUE_100（"100"），taxResidentFlag = TaxResidentFlag.VALUE_2（"2"），isIndividual = "Y"（示例值，本分支不评估），inlandOffshore = "N"（示例值，本分支不评估）
- **WHEN** 执行规则 BR006
- **THEN** 返回 acctNatureNo = AcctNatureNo.VALUE_3606（代码值 "3606"，FTF-区内境外个人自由贸易账户）

### Requirement: REQ-004 对公境外客户判定为境外机构自由贸易账户（FTN）

#### Scenario: REQ-005-S01 同业境外客户判定为 FTU

### Requirement: REQ-006 无匹配条件时不设置自贸区种类
来源：docs/requirements/BR006.md 输出表（acctNatureNo 标记"非必填"）及规则描述 a–e（条件全集）
系统 SHALL 在输入不满足规则描述 a–e 任一条件时（如客户类型为"300-同业"且境内境外标志为"Y-境内"，或客户类型为 a–e 未涉及的取值），不设置 acctNatureNo（输出为空），且不产生其他副作用。

#### Scenario: REQ-006-S01 同业境内客户不设置自贸区种类
- **GIVEN** clientType = ClientType.VALUE_300（"300"），inlandOffshore = "Y"，isIndividual = "N"（示例值），taxResidentFlag = TaxResidentFlag.VALUE_1（示例值）
- **WHEN** 执行规则 BR006
- **THEN** acctNatureNo 为空（不设置任何自由贸易账户种类），无其他输出和副作用

## 验收范围与明确不覆盖的事项

验收范围为上述 REQ-001～REQ-006 的全部场景。

明确不覆盖：

1. 输入必填性的校验执行及空值、非法枚举值输入的行为——需求仅标记必填，未定义缺失或非法时的处理，由上游保证。
2. 客户身份相互矛盾的输入组合（如 isIndividual="Y" 且 clientType="200-对公"）的判定结果——需求未定义；一致输入下五分支互斥，需求未定义亦无需规则间优先级，本 Spec 不增设。
3. isIndividual、inlandOffshore 取 "Y"/"N" 之外值的处理——需求未定义。
4. ClientType.VALUE_600（内部客户）等 a–e 未涉及的业务取值无专门分支，按 REQ-006 输出为空。
5. acctNatureNo 的持久化（写 RB_BUS_ACCT）及之后的业务使用——归属调用方，不在本规则范围。
6. 规则类型标签"断言类"的平台执行语义细节——按规则描述"返回[自贸区种类]"表达为输出取值，平台分类元数据本身不构成行为要求。
