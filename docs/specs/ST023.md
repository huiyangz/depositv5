# ST023 检查机构币种交易权限

## 目标与范围

本任务为交易执行步骤：根据输入{交易机构号}查询【机构币种信息】得到[机构币种列表]，再检查{交易币种}是否在列表范围内——在范围内时检查结果为"通过"并输出命中记录的币种，不在范围内时返回[错误码]"ER0047"。

- 范围内：步骤1–2 的查询条件、成员判定、"通过"与"ER0047"两条结果路径、输出字段 ccy 的取值与空值语义、相关枚举取值绑定。
- 不在范围内：机构币种交易权限检查之外的其他检查（黑名单、限额、检查限制、维护限制等组件）及其在交易编排中的后续使用；机构币种表 FM_BRANCH_CCY 数据的维护；枚举类本身的定义与取值清单维护。

## 正式需求来源

- `docs/requirements/ST023.md`（任务编号 ST023，版本 1，交易执行步骤）
  - 「步骤描述」步骤1「获取机构币种列表」、步骤2「检查交易币种」
  - 「输入」表（2 个字段）、「输出」表（1 个字段）、「相关枚举」、「补充说明」（2 项枚举类绑定）

- 需求无「失败处理」章节；业务失败仅在步骤2正文中以错误码"ER0047"定义。

### 输出

| 字段名 | 类型 | 必填性 | 来源实体 | 说明 |
|--------|------|--------|----------|------|

步骤结果契约（继承 StepResult 的调用成功标志，与业务输出字段区分）：

| 结果路径 | succeed | errorCode | errorMessage | ccy |
|----------|---------|-----------|--------------|-----|
| 检查结果"通过"（{交易币种}在列表内） | true | null | null | 命中记录的币种（等于输入{交易币种}的值） |
| 检查结果"不通过"（否则分支） | false | "ER0047" | 需求未定义，不作断言依据 | null |

说明：

- 「输出」表未定义"检查结果"业务字段，仅有 ccy；步骤2的两种返回（"通过"/[错误码]"ER0047"）按 StepResult 契约（succeed、errorCode、errorMessage 为调用成功标志）表达："通过" = 步骤成功（succeed=true 且错误码为空），"返回错误码 ER0047" = 步骤业务失败（succeed=false 且 errorCode="ER0047"）。
- 输出 ccy 的取值推导：其来源实体为机构币种表（FM_BRANCH_CCY），主键为（归属机构号、币种），同一机构下同一币种至多一条记录；步骤2判定"在范围内"即存在币种等于{交易币种}的记录（至多一条命中），该命中记录的币种即输出 ccy，其值等于输入{交易币种}。判定不通过（含列表为空）时无命中记录，ccy 为空（null，不赋值），与「输出」表"非必填"标记一致。

### 数据访问与依赖

- 【机构币种信息】：机构币种表 FM_BRANCH_CCY，主键为（归属机构号 branch、币种 ccy）。步骤1查询条件仅归属机构号 = 输入{交易机构号}（tranBranch），无其他筛选条件；可能返回 0、1 或多条记录，[机构币种列表]即该查询结果记录集合，每条记录提供一个币种值。
- 数据服务接口：IFmBranchCcyBcc.findByEo（按 EO 属性组合查询，返回记录列表）；EO 字段 branch、ccy 的类型（TranBranch、Ccy）与步骤输入类型一致。
- 本步骤为只读步骤：无外部服务调用、无组件内步骤调用、无数据写入副作用。
- 场景中机构号、币种配置等具体数据均为示例测试数据，不代表真实字典内容。

## Requirements

### Requirement: REQ-001 机构币种列表的获取

来源：`docs/requirements/ST023.md`「步骤描述」步骤1
系统 SHALL 以输入{交易机构号}（tranBranch）为条件查询【机构币种信息】（FM_BRANCH_CCY，按归属机构号匹配，无其他筛选条件），得到[机构币种列表]；列表可能包含零条或多条记录，每条记录提供一个币种值（ccy），供步骤2（REQ-002）判定使用。

#### Scenario: REQ-001-S01 机构存在多条币种记录→列表包含该机构全部币种记录

- **GIVEN** FM_BRANCH_CCY 中归属机构号"351001"（示例，TranBranch.VALUE_351001）存在 2 条记录：ccy=CNY、ccy=USD（示例测试数据）；其他机构存在币种记录（示例：机构"351888"存在 ccy=EUR 的记录）
- **WHEN** 以 tranBranch=TranBranch.VALUE_351001 执行步骤1
- **THEN** 查询仅按归属机构号"351001"匹配，得到 2 条记录的[机构币种列表]（币种为 CNY、USD），不包含其他机构的记录

#### Scenario: REQ-001-S02 机构无任何币种记录→列表为空

- **GIVEN** FM_BRANCH_CCY 中不存在归属机构号"351155"（示例，TranBranch.VALUE_351155）的任何记录
- **WHEN** 以 tranBranch=TranBranch.VALUE_351155 执行步骤1
- **THEN** 得到空列表（0 条记录），无可供步骤2判定的币种，步骤2按"否则"分支处理（见 REQ-002-S03）

### Requirement: REQ-002 交易币种成员判定与结果返回

来源：`docs/requirements/ST023.md`「步骤描述」步骤2、「输出」表
系统 SHALL 判定{交易币种}（tranCcy）是否在[机构币种列表]范围内（存在币种等于{交易币种}的记录）：在范围内时检查结果为"通过"，步骤以成功结束（succeed=true、errorCode=null、errorMessage=null），并将输出 ccy 赋值为命中记录的币种（按主键至多一条命中，其值等于输入{交易币种}）；否则（列表为空，或列表非空但无任何记录币种等于{交易币种}）返回[错误码]"ER0047"，步骤以业务失败结束（succeed=false、errorCode="ER0047"），输出 ccy 为空（null，不赋值）。错误信息（errorMessage）内容需求未定义，不作为验收断言依据。

#### Scenario: REQ-002-S01 交易币种在列表内→通过并输出命中币种

- **GIVEN** 步骤1已按 tranBranch=TranBranch.VALUE_351001 得到[机构币种列表]，记录币种为 CNY、USD（示例测试数据）
- **WHEN** 以 tranCcy=Ccy.USD 执行步骤2判定
- **THEN** USD 在列表范围内，检查结果为"通过"：succeed=true、errorCode=null、errorMessage=null；输出 ccy=Ccy.USD（命中记录的币种，与输入{交易币种}同值）

#### Scenario: REQ-002-S02 列表非空但交易币种不在列表→ER0047

- **GIVEN** 步骤1已按 tranBranch=TranBranch.VALUE_351001 得到[机构币种列表]，记录币种为 CNY、USD（示例测试数据）
- **WHEN** 以 tranCcy=Ccy.EUR 执行步骤2判定
- **THEN** EUR 不在列表范围内：succeed=false、errorCode="ER0047"；输出 ccy 为空（null）；errorMessage 内容需求未定义，不作断言

#### Scenario: REQ-002-S03 列表为空→ER0047

- **GIVEN** 步骤1查询得到的[机构币种列表]为空（机构无任何币种记录，见 REQ-001-S02）
- **WHEN** 以 tranCcy=Ccy.CNY（示例）执行步骤2判定
- **THEN** {交易币种}不在空列表范围内：succeed=false、errorCode="ER0047"；输出 ccy 为空（null）；errorMessage 内容需求未定义，不作断言

## 验收范围与明确不覆盖的事项

### 验收范围

- 2 条需求、5 个验收场景，覆盖：多条币种记录的正常查询路径、查询仅按机构匹配的边界（他机构记录不混入）、列表非空时命中与未命中两条判定分支、列表为空的边界、通过路径的全部结果字段断言（succeed/errorCode/errorMessage/ccy）、ER0047 路径的结果字段与 ccy 空值断言。
- 每个"通过"场景的 THEN 明确成功标志与输出 ccy 的取值来源，每个"ER0047"场景的 THEN 明确失败标志、错误码与 ccy 空值，可直接推导测试断言。

### 明确不覆盖

- {交易机构号}或{交易币种}缺失、为空或枚举外取值时的处理：需求标记必填但未定义校验行为，本 Spec 不发明。
- 错误码"ER0047"对应的错误信息（errorMessage）内容：需求未定义，不作断言依据。
- 技术异常（如数据访问异常）的传播与包装方式：需求未定义，不属于验收场景范围。
- 检查结果在后续交易流程中的使用、其他检查组件的联动、FM_BRANCH_CCY 数据的维护、枚举类取值清单维护。
- 本任务无组件内步骤调用补充说明，该约定为不适用。
