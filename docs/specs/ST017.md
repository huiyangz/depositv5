# ST017 设置贷记交易的借贷标志

## 目标与范围

ST017 是贷记交易执行流程中的一个步骤：执行时将输出数据项 [借贷标志]（别名"输出数据-借贷标志"）无条件赋值为固定值"C-贷方"，作为步骤输出供交易后续环节使用。

范围内：

- 本步骤执行时对输出字段 crDrInd 的赋值行为、成功结果及无副作用约束。
- 输出字段 crDrInd 的类型与取值域绑定（代码[借贷标志] ↔ com.dcits.depsit.enums.CrDrInd）。

不在范围内：

- 所属贷记交易的整体编排、本步骤的调用位置与步骤间数据流转（由交易层任务定义，本需求未涉及）。
- 借贷标志在交易流水等数据实体中的写入与后续使用。
- 枚举 com.dcits.depsit.enums.CrDrInd 的定义与维护（工程既有资产，本步骤仅引用）。

## Requirements

### Requirement: REQ-001 赋值借贷标志为"C-贷方"
来源：`docs/requirements/ST017.md`「步骤描述」第 1 条（原文："赋值借贷标志：赋值[借贷标志]为'C-贷方'"）
系统 SHALL 在本步骤执行时将输出字段 crDrInd（借贷标志）无条件赋值为"C-贷方"，即枚举值 com.dcits.depsit.enums.CrDrInd.C；赋值不依赖任何输入、数据状态或外部调用。

#### Scenario: REQ-001-S01 执行赋值（唯一路径）
- **GIVEN** 本步骤被调用（无输入字段，无前置数据条件）
- **WHEN** 执行步骤 ST017
- **THEN** 输出 crDrInd = CrDrInd.C（value "C"，语义为贷方，即需求所述"C-贷方"）；输出 succeed = true，errorCode 与 errorMessage 均为 null；全程不发生任何数据实体的读取或写入，不调用任何其他组件接口（无副作用）

### Requirement: REQ-002 借贷标志输出字段与取值域绑定
来源：`docs/requirements/ST017.md`「输出」表、「相关枚举」表、「补充说明」（原文："{借贷标志,输出数据-借贷标志}取值来源于代码[借贷标志]，对应枚举类-类名：com.dcits.depsit.enums.CrDrInd"）
系统 SHALL 以字段 crDrInd 输出借贷标志（数据项别名：借贷标志、输出数据-借贷标志），字段类型为 com.dcits.depsit.enums.CrDrInd，取值域为代码[借贷标志]（C-贷、D-借）；本步骤输出取值仅可能为"C-贷方"（CrDrInd.C）。

#### Scenario: REQ-002-S01 输出取值属于代码[借贷标志]取值域
- **GIVEN** 枚举类 com.dcits.depsit.enums.CrDrInd 定义了代码[借贷标志]的取值域：C（"C"，贷）、D（"D"，借）
- **WHEN** 读取本步骤输出的借贷标志字段 crDrInd
- **THEN** 字段为 com.dcits.depsit.enums.CrDrInd 类型，取值为取值域中的"C-贷方"（CrDrInd.C），不出现"D-借方"（CrDrInd.D）或取值域外的值
