# ST075 设置账户执行利率

## 目标与范围

本任务为存款交易编排中的交易执行步骤：将调用方传入的 $执行利率$（realRate）原值赋值到账户的 $执行利率$ 字段，并通过步骤输出返回，供后续步骤使用。

- 任务编号：ST075（系统 SYS-1146），所属组件：存款业务组件（deposit / deposit-service），版本 v1。
- 范围：单一步骤"设置账户执行利率"的输入、赋值行为、输出与失败表达方式。
- 不在范围内：
  - 执行利率的计算（属账户执行利率计算规则任务，本步骤只接收计算结果）；
  - 对公存款利息明细表（RB_BUS_ACCT_INT_DETAIL）的数据库读写（步骤描述仅含赋值指令，无查询、新增、修改指令）；
  - 对输入值的服务端必填校验、值域校验（需求未要求，必填性为调用方契约）；
  - 本步骤在交易编排中的调用时机、顺序及上下游装配。

## 正式需求来源

- 正式需求：`docs/requirements/ST075.md`（本 Spec 唯一业务事实来源），章节：步骤描述（1 条）、输入、输出、失败处理。

- 无组件内步骤调用补充说明，无关联任务 Spec 依赖。

## 输入、输出及依赖契约

输入（由交易编排提供，来源实体未指定）：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| realRate | java.math.BigDecimal | 必填 | 执行利率（步骤描述中的 [执行利率] 即本字段） |

输出：

| 字段 | 类型 | 必填（源文档标记） | 实体绑定 | 说明 |
|------|------|------|----------|------|
| realRate | java.math.BigDecimal | 非必填 | 对公存款利息明细表（RB_BUS_ACCT_INT_DETAIL）$执行利率$（REAL_RATE） | 执行利率 |

- 值语义：赋值为原值传递，BigDecimal 的数值与标度均不变；不换算、不舍入、不做空值转换。需求未约定精度、标度、舍入与值域限制（不适用）。
- 必填性语义：输入 realRate 必填为调用方契约，本步骤不做校验；输出字段源文档标记非必填，但本步骤正常返回时 realRate 恒等于非空输入，不存在置空分支。
- 实体绑定说明：步骤描述中"账户$执行利率$"为目标工作字段，其实体绑定以输出表声明为准，即 RB_BUS_ACCT_INT_DETAIL 的执行利率字段（代码核对：`RbBusAcctIntDetailEO.realRate`，BigDecimal，字段说明"执行利率"；系统内无其他账户表含执行利率字段）。本步骤不触发该实体的数据库访问。
- 工程契约（技术约束，非业务规则）：步骤输出 BO 继承 `StepResult`（`succeed` / `errorCode` / `errorMessage`），正常返回 `succeed=true` 且错误字段为 null。
- 依赖调用：无。不调用任何组件接口、规则或其他步骤。
- 副作用：无。不读写数据库、不修改输入对象、不产生外部调用。

## Requirements

### Requirement: REQ-001 赋值账户执行利率
来源：`docs/requirements/ST075.md` 步骤描述第 1 条"设置账户执行利率：赋值账户$执行利率$为[执行利率]"；输入表；输出表。
系统 SHALL 在步骤执行时将输入 $执行利率$（realRate）原值赋值到输出 $执行利率$（realRate，绑定对公存款利息明细表 RB_BUS_ACCT_INT_DETAIL 的执行利率字段）；赋值过程 MUST NOT 对值做任何换算、舍入、标度调整、空值转换或条件分支处理，且 MUST NOT 产生数据库读写、组件调用等任何副作用。

#### Scenario: REQ-001-S01 正常赋值
- **GIVEN** 步骤输入 realRate = 0.017（java.math.BigDecimal，示例值，标度 3）
- **WHEN** 执行本步骤
- **THEN** 输出 realRate = 0.017，数值与标度与输入完全一致；输出 succeed = true，errorCode 与 errorMessage 为 null；无数据库读写、无组件调用（无副作用）

#### Scenario: REQ-001-S02 无分支的值传递
- **GIVEN** 步骤输入 realRate = -0.002（java.math.BigDecimal，示例值，负数，标度 3）
- **WHEN** 执行本步骤
- **THEN** 输出 realRate = -0.002，与输入原值一致；步骤不因符号、大小或取值做任何分支、过滤或改写，返回 succeed = true 且无错误信息

### Requirement: REQ-002 无业务失败场景
来源：`docs/requirements/ST075.md` 失败处理"本步骤无业务失败场景，失败仅由技术异常传播表达"。
系统 SHALL 不为本步骤定义任何业务失败路径：步骤正常返回时 MUST 携带 succeed = true 且 errorCode、errorMessage 为 null；失败仅能以技术异常形式向上传播，MUST NOT 捕获、转换或吞掉技术异常，也 MUST NOT 以业务失败输出替代异常。

#### Scenario: REQ-002-S01 正常返回即成功
- **GIVEN** 任意满足必填契约的输入（realRate 为非空 BigDecimal）
- **WHEN** 步骤正常返回
- **THEN** succeed = true，errorCode = null，errorMessage = null；不存在返回业务错误码或错误信息的执行路径

#### Scenario: REQ-002-S02 失败仅以技术异常表达
- **GIVEN** 本步骤不存在业务失败分支，步骤逻辑中无业务错误码定义
- **WHEN** 步骤执行中出现技术异常
- **THEN** 该异常原样向上传播（不捕获、不转换、不吞掉），调用方不会收到带 errorCode / errorMessage 的业务失败输出

## 验收范围与明确不覆盖的事项

验收范围（以本 Spec 场景为测试设计依据，非已生成的测试或执行结果）：
- 输出 realRate 与输入原值一致（数值与标度），含正、负等代表值；
- 正常返回 succeed = true 且无错误码、错误信息；
- 无数据库副作用、无组件调用；
- 技术异常不被捕获、转换或吞掉。

明确不覆盖：
- 执行利率的计算规则与来源正确性（属计算规则任务）；
- RB_BUS_ACCT_INT_DETAIL 的持久化及字段落库（本步骤无数据库操作）；
- 输入必填性的运行时校验行为（必填为调用方契约，需求未要求步骤校验，空输入不属于本步骤已定义行为）；
- 交易编排中本步骤的调用时机、顺序及与上下游步骤的数据流装配；
- 精度、标度、舍入与值域约束（需求未约定，本步骤仅原值传递）。
