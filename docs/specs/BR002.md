# BR002 计算账户利率

## 目标与范围

BR002 为存款业务组件（deposit-service）的计算类规则：以{产品利率}为基准，结合账户侧三种利率浮动配置（账户利率浮动百分点、账户利率浮动百分比、账户固定利率），按固定优先级判定命中分支，计算并返回[执行利率]（realRate）。

本 Spec 覆盖：

- 条件分支 a/b/c 的判定条件、链式优先级与计算公式
- 浮动输入为 null 时的分支判定口径（依据输入表"非必填"标记与已接受处理结论映射）
- a/b/c 均未命中时的输出口径（依据规则无默认分支与输出表"非必填"标记映射）
- 输入输出字段契约：字段名、类型、必填性、null 语义、数值比较口径

不在本 Spec 范围：

- 结果精度、标度与舍入规则（需求未规定）
- productRate 缺失或非法时的处理（输入表标记"必填"，必填性由调用方契约保证；需求未定义违反行为）
- 利率上下限、合规性等数值校验（需求未要求）
- 规则的触发时机、持久化与调用编排（属调用方任务；本规则为纯计算，无数据库访问、无外部服务调用、无状态副作用）

## 输入、输出及依赖契约

### 输入

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| acctSpreadRate | java.math.BigDecimal | 否 | 账户利率浮动百分点 |
| acctPercentRate | java.math.BigDecimal | 否 | 账户利率浮动百分比 |
| acctFixedRate | java.math.BigDecimal | 否 | 账户固定利率 |
| productRate | java.math.BigDecimal | 是 | 产品利率 |

- 来源实体：需求未指定（输入表"来源实体"列为空），四个字段均为规则入参。
- null 语义：三个浮动字段允许 null（非必填），判定口径见 REQ-002；productRate 必填，缺失时的行为需求未定义，本 Spec 不为其设计场景。

### 输出

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| realRate | java.math.BigDecimal | 否（a/b/c 均未命中时不赋值，见 REQ-003） | 执行利率 |

### 判定与运算口径

- "不等于0"为数值比较，采用 BigDecimal 数值比较口径（compareTo 语义）：0、0.0、0.00 等任意标度表示均视为等于 0；一切非 0 数值（含负数）视为不等于 0。输出断言同样按数值比较（如 0.030 与 0.03 视为相等）。
- null 不作为数值参与任何公式运算；null 与 0 在分支选择上行为一致（对应分支均不命中，见 REQ-002）。
- 三个公式均为 BigDecimal 精确运算（加法、乘法），不引入中间舍入；需求未规定结果精度与舍入，本 Spec 不约束结果标度，场景期望值均选为可精确表示的数值（以下场景取值均为示例数据，非规范常量）。
- 依赖：无数据库访问、无外部服务/组件调用、无状态副作用；输出仅由四个入参决定。分支c 不使用 productRate。

## Requirements

### Requirement: REQ-001 按优先级判定分支并计算执行利率

来源：docs/requirements/BR002.md"规则描述"第7行 a/b/c 条款。原文："a.若{账户利率浮动百分点}不等于0，那么返回[执行利率]等于{产品利率}+{账户利率浮动百分点}；b.否则若{账户利率浮动百分比}不等于0，那么返回[执行利率]等于{产品利率}*（1+{账户利率浮动百分比}）；c.否则若{账户固定利率}不等于0，那么返回[执行利率]等于{账户固定利率}"。

系统 SHALL 按 a → b → c 的顺序以"否则若"链式判定，首个命中的分支决定执行利率，且 SHALL 仅执行命中分支的公式、不再判定后续分支：

- 分支a：acctSpreadRate 不等于 0 → realRate = productRate + acctSpreadRate
- 分支b：分支a未命中且 acctPercentRate 不等于 0 → realRate = productRate ×（1 + acctPercentRate）
- 分支c：分支a、b均未命中且 acctFixedRate 不等于 0 → realRate = acctFixedRate（不使用 productRate）

#### Scenario: REQ-001-S01 浮动百分点命中（分支a）
- **GIVEN** productRate=0.025、acctSpreadRate=0.005、acctPercentRate=0、acctFixedRate=0
- **WHEN** 执行规则计算执行利率
- **THEN** 命中分支a，realRate = 0.025 + 0.005 = 0.030（精确加法，无舍入）

#### Scenario: REQ-001-S02 浮动百分比命中（分支b）
- **GIVEN** productRate=0.025、acctSpreadRate=0、acctPercentRate=0.1、acctFixedRate=0
- **WHEN** 执行规则计算执行利率
- **THEN** 分支a未命中（acctSpreadRate 等于 0），命中分支b，realRate = 0.025 ×（1+0.1）= 0.0275

#### Scenario: REQ-001-S03 账户固定利率命中（分支c）
- **GIVEN** productRate=0.025、acctSpreadRate=0、acctPercentRate=0、acctFixedRate=0.031
- **WHEN** 执行规则计算执行利率
- **THEN** 分支a、b均未命中，命中分支c，realRate = 0.031（与 productRate 取值无关）

#### Scenario: REQ-001-S04 三个条件同时满足时分支a优先
- **GIVEN** productRate=0.025、acctSpreadRate=0.005、acctPercentRate=0.1、acctFixedRate=0.031
- **WHEN** 执行规则计算执行利率
- **THEN** 仅命中分支a，realRate = 0.030；不执行分支b、c 的公式

#### Scenario: REQ-001-S05 分支b、c 同时满足时分支b优先
- **GIVEN** productRate=0.025、acctSpreadRate=0、acctPercentRate=0.1、acctFixedRate=0.031
- **WHEN** 执行规则计算执行利率
- **THEN** 仅命中分支b，realRate = 0.0275；不执行分支c 的公式

#### Scenario: REQ-001-S06 负值浮动百分点命中分支a
- **GIVEN** productRate=0.025、acctSpreadRate=-0.005、acctPercentRate=0、acctFixedRate=0
- **WHEN** 执行规则计算执行利率
- **THEN** -0.005 不等于 0，命中分支a，realRate = 0.025 +（-0.005）= 0.020

#### Scenario: REQ-001-S07 负值浮动百分比命中分支b
- **GIVEN** productRate=0.025、acctSpreadRate=0、acctPercentRate=-0.1、acctFixedRate=0
- **WHEN** 执行规则计算执行利率
- **THEN** 命中分支b，realRate = 0.025 ×（1-0.1）= 0.0225

#### Scenario: REQ-001-S08 数值上等于0的任意标度表示不命中分支a
- **GIVEN** productRate=0.025、acctSpreadRate=0.00（数值上等于0）、acctPercentRate=0.1、acctFixedRate=0
- **WHEN** 执行规则计算执行利率
- **THEN** 分支a未命中（0.00 按数值比较等于 0），命中分支b，realRate = 0.0275

### Requirement: REQ-002 浮动输入为 null 时对应分支不命中

来源：docs/requirements/BR002.md"输入"第13-15行（三个浮动字段均标记"非必填"，允许 null）；"已接受的需求处理结论"第30-36行（null 判定口径事项已豁免）。本条为该已接受结论的映射整理，不是需求方补充的业务取值：null 表示未配置该浮动方式，对应分支不命中，null 不作为数值参与运算。

系统 SHALL 将为 null 的浮动输入判定为其对应分支条件不满足，并按优先级继续判定下一分支；null SHALL NOT 作为 0 或任何数值代入公式运算（null 与 0 在分支选择上行为一致）。

#### Scenario: REQ-002-S01 浮动百分点为 null 时判定下一分支
- **GIVEN** productRate=0.025、acctSpreadRate=null、acctPercentRate=0.1、acctFixedRate=0
- **WHEN** 执行规则计算执行利率
- **THEN** 分支a不命中（null 不满足"不等于0"），命中分支b，realRate = 0.025 ×（1+0.1）= 0.0275

#### Scenario: REQ-002-S02 前两项为 null 时固定利率命中
- **GIVEN** productRate=0.025、acctSpreadRate=null、acctPercentRate=null、acctFixedRate=0.031
- **WHEN** 执行规则计算执行利率
- **THEN** 分支a、b均不命中，命中分支c，realRate = 0.031

#### Scenario: REQ-002-S03 首分支已命中时后续分支字段为 null 不影响结果
- **GIVEN** productRate=0.025、acctSpreadRate=0.005、acctPercentRate=null、acctFixedRate=null
- **WHEN** 执行规则计算执行利率
- **THEN** 命中分支a，realRate = 0.030（后续分支字段为 null 不影响已命中分支的判定与计算）

### Requirement: REQ-003 全部分支未命中时不产生执行利率

来源：docs/requirements/BR002.md"规则描述"第7行（仅定义 a/b/c 三个"否则若"分支，无默认分支）；"输出"第22行（realRate 标记"非必填"）；"已接受的需求处理结论"第30-36行（默认分支事项已豁免；知识库咨询亦确认"默认等于产品利率"无依据，见 outputs/知识库咨询记录.md 2026-09-29 条目）。本条为上述事实的映射整理，不是需求方补充的业务取值。

系统 SHALL 在 a、b、c 三个条件均不满足时不对 realRate 赋值（realRate 为 null），SHALL NOT 返回任何默认利率（包括 productRate）。

#### Scenario: REQ-003-S01 三项浮动均为 0
- **GIVEN** productRate=0.025、acctSpreadRate=0、acctPercentRate=0、acctFixedRate=0
- **WHEN** 执行规则计算执行利率
- **THEN** 无分支命中，realRate = null（不返回默认值）

#### Scenario: REQ-003-S02 三项浮动均为 null
- **GIVEN** productRate=0.025、acctSpreadRate=null、acctPercentRate=null、acctFixedRate=null
- **WHEN** 执行规则计算执行利率
- **THEN** 无分支命中，realRate = null

#### Scenario: REQ-003-S03 0 与 null 混合且均不满足条件
- **GIVEN** productRate=0.025、acctSpreadRate=0、acctPercentRate=null、acctFixedRate=0.00
- **WHEN** 执行规则计算执行利率
- **THEN** 无分支命中，realRate = null
