# BR002 计算账户利率

## 目标与范围

本任务为存款业务组件（deposit）内的计算类规则：根据账户层利率调整字段与产品利率，计算账户执行利率 `realRate`。

- 目标：按"浮动百分点 → 浮动百分比 → 固定利率 → 产品利率"的优先级顺序，取第一个成立的分支计算并返回执行利率。
- 范围：单条计算规则的输入契约、条件判断（含空值语义与优先级）、计算公式与输出契约。
- 不在范围：入参必填校验及缺失时的报错（`prodRate` 为必填，需求未规定规则内处理）；利率数据的存取与来源实体绑定（需求来源实体栏为空）；执行利率的后续使用（计息、展示等）；与其他规则的编排组合。

## 输入、输出及依赖契约

### 输入

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| acctSpreadRate | java.math.BigDecimal | 否 | 账户利率浮动百分点；空值视同 0 参与条件判断 |
| acctPercentRate | java.math.BigDecimal | 否 | 账户利率浮动百分比；空值视同 0 参与条件判断 |
| acctFixedRate | java.math.BigDecimal | 否 | 账户固定利率；空值视同 0 参与条件判断 |
| prodRate | java.math.BigDecimal | 是 | 产品利率 |

### 输出

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| realRate | java.math.BigDecimal | 是 | 执行利率；任一分支命中均返回非空结果 |

### 计算语义（测试断言依据，不新增业务）

- 条件判断"不等于 0"按**数值**比较：空值与数值 0（含 0、0.0、0.00 等任意标度）均判为"等于 0"，条件不成立；任何非零数值（含负数）条件成立。
- 空值仅在条件判断中视同 0：命中 a/b/c 分支时对应字段必为非空非零，空值不会进入算术运算；分支 d 直接返回 `prodRate`。
- 计算仅含加法与乘法，`BigDecimal` 下均可精确表示，不产生舍入。需求未规定结果标度与舍入规则，本 Spec 不引入；结果标度依循 BigDecimal 运算语义（加法取两操作数标度最大值，乘法取标度之和）。场景中的数值均为示例数据。
- 无平台服务依赖、无组件内步骤调用、无数据库读写副作用。

## Requirements

### Requirement: REQ-001 浮动百分点命中时按产品利率加点计算
来源：`docs/requirements/BR002.md` 规则描述 a 条；输入表 `acctSpreadRate`、`prodRate`；输出表 `realRate`
系统 SHALL 在账户利率浮动百分点 `acctSpreadRate` 数值不等于 0（空值视同 0）时，返回执行利率 `realRate = prodRate + acctSpreadRate`，并停止评估 b、c、d 分支。

#### Scenario: REQ-001-S01 浮动百分点为正值
- **GIVEN** `prodRate` 为 0.015，`acctSpreadRate` 为 0.002，`acctPercentRate` 为空，`acctFixedRate` 为空
- **WHEN** 计算账户利率
- **THEN** 返回 `realRate` = 0.015 + 0.002 = 0.017；`acctPercentRate`、`acctFixedRate` 不参与计算

#### Scenario: REQ-001-S02 浮动百分点为负值
- **GIVEN** `prodRate` 为 0.015，`acctSpreadRate` 为 -0.002，`acctPercentRate` 为空，`acctFixedRate` 为空
- **WHEN** 计算账户利率
- **THEN** 负值不等于 0，a 条件成立；返回 `realRate` = 0.015 + (-0.002) = 0.013

#### Scenario: REQ-001-S03 三项调整同时非零时仍优先使用浮动百分点
- **GIVEN** `prodRate` 为 0.015，`acctSpreadRate` 为 0.002，`acctPercentRate` 为 0.1，`acctFixedRate` 为 0.02
- **WHEN** 计算账户利率
- **THEN** 返回 `realRate` = 0.015 + 0.002 = 0.017；b、c 分支不生效

### Requirement: REQ-002 浮动百分比在点数不成立时按比例计算
来源：`docs/requirements/BR002.md` 规则描述 b 条；输入表 `acctPercentRate`；输出表 `realRate`
系统 SHALL 在 `acctSpreadRate` 为空或等于 0，且 `acctPercentRate` 数值不等于 0 时，返回 `realRate = prodRate × (1 + acctPercentRate)`，并停止评估 c、d 分支。

#### Scenario: REQ-002-S01 浮动百分比为正值且点数为数值零
- **GIVEN** `prodRate` 为 0.015，`acctSpreadRate` 为 0.00（数值零），`acctPercentRate` 为 0.1，`acctFixedRate` 为 0.02
- **WHEN** 计算账户利率
- **THEN** 返回 `realRate` = 0.015 × (1 + 0.1) = 0.0165；`acctFixedRate` 虽非零但不参与计算（b 优先于 c）

#### Scenario: REQ-002-S02 浮动百分点为空
- **GIVEN** `prodRate` 为 0.015，`acctSpreadRate` 为空，`acctPercentRate` 为 0.1，`acctFixedRate` 为空
- **WHEN** 计算账户利率
- **THEN** 空值视同 0，a 条件不成立；返回 `realRate` = 0.015 × (1 + 0.1) = 0.0165

#### Scenario: REQ-002-S03 浮动百分比为负值
- **GIVEN** `prodRate` 为 0.015，`acctSpreadRate` 为空，`acctPercentRate` 为 -0.1，`acctFixedRate` 为空
- **WHEN** 计算账户利率
- **THEN** 负值不等于 0，b 条件成立；返回 `realRate` = 0.015 × (1 - 0.1) = 0.0135

### Requirement: REQ-003 账户固定利率在前两项不成立时直接生效
来源：`docs/requirements/BR002.md` 规则描述 c 条；输入表 `acctFixedRate`；输出表 `realRate`
系统 SHALL 在 `acctSpreadRate`、`acctPercentRate` 均为空或等于 0，且 `acctFixedRate` 数值不等于 0 时，返回 `realRate = acctFixedRate`（不与 `prodRate` 运算），并停止评估 d 分支。

#### Scenario: REQ-003-S01 账户固定利率为正值
- **GIVEN** `prodRate` 为 0.015，`acctSpreadRate` 为空，`acctPercentRate` 为 0.00（数值零），`acctFixedRate` 为 0.02
- **WHEN** 计算账户利率
- **THEN** 返回 `realRate` = 0.02；`prodRate` 不参与该分支计算

#### Scenario: REQ-003-S02 账户固定利率为负值
- **GIVEN** `prodRate` 为 0.015，`acctSpreadRate` 为空，`acctPercentRate` 为空，`acctFixedRate` 为 -0.005
- **WHEN** 计算账户利率
- **THEN** 负值不等于 0，c 条件成立；返回 `realRate` = -0.005

### Requirement: REQ-004 全部条件不成立时默认返回产品利率
来源：`docs/requirements/BR002.md` 规则描述 d 条及"空值视同0参与条件判断"；输入表 `prodRate`；输出表 `realRate`
系统 SHALL 在 `acctSpreadRate`、`acctPercentRate`、`acctFixedRate` 均为空或等于 0 时，返回 `realRate = prodRate`。

#### Scenario: REQ-004-S01 三个账户利率字段均为空
- **GIVEN** `acctSpreadRate`、`acctPercentRate`、`acctFixedRate` 均为空，`prodRate` 为 0.015
- **WHEN** 计算账户利率
- **THEN** 三个空值均视同 0，a、b、c 条件均不成立；返回 `realRate` = 0.015

#### Scenario: REQ-004-S02 空值与数值零混合
- **GIVEN** `acctSpreadRate` 为 0.000，`acctPercentRate` 为空，`acctFixedRate` 为 0，`prodRate` 为 0.015
- **WHEN** 计算账户利率
- **THEN** 数值零（任意标度）与空值同样判为"等于 0"，a、b、c 条件均不成立；返回 `realRate` = 0.015

- 执行利率的持久化、展示与后续计息使用。
- 规则的并发、性能与事务要求。
