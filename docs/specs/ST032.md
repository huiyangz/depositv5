# ST032 设置借记交易的借贷标志

## 目标与范围

本任务为交易执行步骤：为借记交易设置借贷标志，将输出数据[借贷标志]（别名"输出数据-借贷标志"，字段 crDrInd）无条件赋值为"D-借方"，即枚举 `com.dcits.depsit.enums.CrDrInd.D`（value "D"），并作为步骤输出返回。

- 范围内：赋值规则与赋值常量、输出字段契约（字段名、类型、必填性、空值语义）、借贷标志的枚举类绑定与取值映射、失败处理约定。
- 不在范围内：借贷标志在后续交易流程（记账方向、余额计算等）中的使用；贷记交易（贷方标志）等其他交易的借贷标志设置；交易编排中其他步骤的行为；枚举类 CrDrInd 的定义与取值清单维护。

  - 「步骤描述」第 1 条（赋值[借贷标志]为"D-借方"）
  - 「输出」表（1 个字段：crDrInd）、「相关枚举」、「补充说明」（枚举类绑定）、「失败处理」
