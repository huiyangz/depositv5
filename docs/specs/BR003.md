# BR003 检查允许转久悬标志

## 目标与范围

- 本任务实现一条断言类规则：依据输入字段「允许账户转久悬标志」（allowSuspendFlag）与「是否允许转久悬」（allowDormantFlag）判定是否允许转久悬，返回二值断言结果「是」或「否」。
- 范围：仅本规则的输入输出契约与判定逻辑（规则描述条目 a、b、c 的完整分支与空值口径）。
- 不在范围：必填输入缺失时的处理、字段取值域校验、转久悬交易编排与账户久悬状态维护、断言结果的后续消费逻辑。

## 正式需求来源

- `docs/requirements/BR003.md`（BR003 检查允许转久悬标志，规则类型：断言类）：
  - 「规则描述」条目 a（第 7 行）、条目 b（第 8 行）、条目 c（第 10 行）；
  - 「输入」表（第 14–17 行）：allowSuspendFlag（必填）、allowDormantFlag（非必填）两行；
  - 「补充说明」（第 21 行）：可能相关的属性「允许账户转久悬标志」，类型为 java.lang.String；
  - 「已接受的需求处理结论」：条件 b「等于空」的 null/空字符串歧义已按需求处理流程放行，按当前正文执行，后续生成与审核不再以该事项阻断；处理记录不补充未写明的业务取值。
- 关联正式 Spec：无（需求未声明对其他任务 Spec 的依赖，仓库 `docs/specs/` 下不存在本任务声明的关联 Spec）。

## 输入、输出及依赖契约

输入字段（名称、类型、必填性均取自需求「输入」表，为规范契约，非示例数据）：

| 字段名 | 类型 | 必填性 | 空值语义 | 说明 |
|--------|------|--------|----------|------|
| allowSuspendFlag | java.lang.String | 必填 | 需求未定义必填缺失时的处理（见验收范围） | 允许账户转久悬标志；规则比较字面量为 "Y"、"N"（规范常量） |
| allowDormantFlag | java.lang.String | 非必填 | 「空」= null（未传入该字段），见下方空值口径 | 是否允许转久悬；规则比较字面量为 "N"（规范常量） |

空值口径（本 Spec 的规范性定义）：

- 条件 b 中「{是否允许转久悬}等于空」指 allowDormantFlag 的值为 null（调用方未传入该字段）。
- 空字符串 "" 是已传入的取值，不等于「空」：不满足条件 b 的空值比较，也不等于条件 a 比较所需的 "N"，落入条件 c。
- 依据：需求将 allowDormantFlag 声明为非必填 java.lang.String，「空」与显式取值 "Y"/"N" 并列指未传值；该口径的歧义已在需求处理中放行，本 Spec 按 null 口径固化为唯一可验证定义。

比较语义：规则中「等于」均按 java.lang.String 字面量精确相等执行；"Y"、"N"、null 为规范常量，场景中其余具体取值为示例数据。

输出：

- 断言结果，二值：「是」或「否」（规范常量，与规则描述原文一致）；每次判定有且仅有一个返回值。
- 输出载体类型：需求未声明，不适用（测试按「是/否」取值断言）。

依赖与副作用：

- 无外部服务调用、无数据库读取、无状态修改；判定除返回结果外无其他副作用（需求未声明任何依赖与来源实体）。
- 技术锚点确认（不改写业务）：工程实体 `RbBusAcct.allowSuspendFlag`（String，注释「允许账户转久悬标志」）与需求输入字段同名同义，对应「补充说明」中"可能相关的属性"；需求未声明来源实体，字段由调用方按参数传入。

## Requirements

### Requirement: REQ-001 允许转久悬断言判定
来源：docs/requirements/BR003.md「规则描述」条目 a、b、c（第 7、8、10 行）；「输入」表
系统 SHALL 对输入 allowSuspendFlag、allowDormantFlag 完成断言判定，且有且仅有一个返回值：

- 条件 a：allowSuspendFlag 等于 "Y" 且 allowDormantFlag 等于 "N" 时，返回「否」；
- 条件 b：allowSuspendFlag 等于 "N" 且 allowDormantFlag 等于空（null，未传入）时，返回「否」；
- 条件 c：不满足条件 a 且不满足条件 b 的其余全部输入组合，返回「是」。

条件 a 与条件 b 在同一输入上互斥（"Y" ≠ "N"），任一输入组合恰落入一个分支。判定除返回结果外 MUST NOT 产生其他副作用（不修改输入、不发起外部调用、不变更任何状态）。

#### Scenario: REQ-001-S01 条件 a 命中返回否
- **GIVEN** allowSuspendFlag 值为 "Y"，allowDormantFlag 值为 "N"（示例数据，满足类型与必填性约束）
- **WHEN** 执行本规则判定
- **THEN** 返回「否」；输入字段值不变，无外部调用与状态变更

#### Scenario: REQ-001-S02 条件 b 命中返回否
- **GIVEN** allowSuspendFlag 值为 "N"，allowDormantFlag 未传入（值为 null）
- **WHEN** 执行本规则判定
- **THEN** 返回「否」；输入字段值不变，无外部调用与状态变更

#### Scenario: REQ-001-S03 账户允许且显式允许转久悬返回是
- **GIVEN** allowSuspendFlag 值为 "Y"，allowDormantFlag 值为 "Y"
- **WHEN** 执行本规则判定
- **THEN** 条件 a 因 allowDormantFlag 不等于 "N" 不满足，条件 b 因 allowSuspendFlag 不等于 "N" 不满足，按条件 c 返回「是」

#### Scenario: REQ-001-S04 账户允许且未传入是否允许转久悬返回是
- **GIVEN** allowSuspendFlag 值为 "Y"，allowDormantFlag 未传入（值为 null）
- **WHEN** 执行本规则判定
- **THEN** 条件 a 因 allowDormantFlag 不等于 "N" 不满足，条件 b 因 allowSuspendFlag 不等于 "N" 不满足，按条件 c 返回「是」

#### Scenario: REQ-001-S05 账户不允许但显式允许转久悬返回是
- **GIVEN** allowSuspendFlag 值为 "N"，allowDormantFlag 值为 "Y"
- **WHEN** 执行本规则判定
- **THEN** 条件 b 因 allowDormantFlag 不为空（null）不满足，条件 a 因 allowSuspendFlag 不等于 "Y" 不满足，按条件 c 返回「是」

#### Scenario: REQ-001-S06 空字符串不视为空返回是
- **GIVEN** allowSuspendFlag 值为 "N"，allowDormantFlag 值为空字符串 ""（非必填 String 的已传值，属合法输入）
- **WHEN** 执行本规则判定
- **THEN** 按空值口径 "" 不等于「空」（null），条件 b 不满足；条件 a 因 allowSuspendFlag 不等于 "Y" 不满足，按条件 c 返回「是」
