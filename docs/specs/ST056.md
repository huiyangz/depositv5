# ST056 检查利率浮动类型

## 目标与范围

本任务为交易执行步骤：对输入的{账户利率浮动百分点}（acctSpreadRate）、{账户利率浮动百分比}（acctPercentRate）、{账户固定利率}（acctFixedRate）三个字段做必输性（互斥性）检查——三者中恰有一个不为空时检查通过；否则以错误码"ER0032"业务失败返回。

- 范围内：三个输入字段的空/非空组合判定、通过结果的返回、错误码"ER0032"的失败返回、输入字段契约与空值语义。
- 不在范围内：三个利率字段取值范围、精度、正负等数值合理性校验（如利率类型、执行利率范围检查，属其他任务）；ER0032 失败在交易编排中的后续处理（短路、补偿等）；错误码资源的维护；字段的上游来源与赋值。

## 正式需求来源

- `docs/requirements/ST056.md`（任务编号 ST056，版本 1，交易执行步骤）
  - 「步骤描述」第 1 条：检查利率浮动信息必输性——三者只有一个不为空→检查结果"通过"，否则→[错误码]"ER0032"
  - 「输入」表（3 个字段，均为 java.math.BigDecimal、非必填、来源实体为空）
- 需求无「输出」表、「相关枚举」、「补充说明」、「失败处理」章节：本步骤的业务失败即步骤描述定义的 ER0032，无其他失败场景。
- 关联正式 Spec：无。本步骤为纯输入校验，无组件内步骤调用、无数据访问、无外部服务依赖，`docs/specs/` 下无本任务依赖的已合并 Spec。

## 输入、输出及依赖契约

### 输入

| 字段名 | 类型 | 必填性 | 说明 |
|--------|------|--------|------|
| acctFixedRate | java.math.BigDecimal | 非必填 | 账户固定利率 |
| acctPercentRate | java.math.BigDecimal | 非必填 | 账户利率浮动百分比 |
| acctSpreadRate | java.math.BigDecimal | 非必填 | 账户利率浮动百分点 |

空值语义：{字段}"为空"指字段值为 null；"不为空"指字段值为任意非 null 的 BigDecimal 数值（含 0）。三字段均非必填与判定规则一致：任意空/非空组合均可上送，组合是否合法由本步骤判定，本步骤不对上送方做前置校验。需求「来源实体」列为空，本步骤不访问任何数据实体。

### 输出（StepResult 契约绑定）

需求未定义独立输出字段表；可观察结果通过步骤输出契约 `com.dcits.common.step.StepResult`（succeed / errorCode / errorMessage）表达：

| 判定结果 | succeed | errorCode | errorMessage |
|----------|---------|-----------|--------------|
| 三者恰一不为空（"通过"） | true | null | null |
| 否则（0 个、2 个或 3 个不为空） | false | "ER0032"（规范常量） | 按工程错误码资源 `errorcodes.properties` 中 ER0032 既有文案："账户利率浮动百分点，账户利率浮动百分比，账户固定利率只能上送一个"（技术约束，非需求义务） |

错误码 "ER0032" 为需求正文明确的规范常量；错误信息文案为工程既有资源条目，需求仅约束错误码本身。

- 无数据访问、无外部服务调用、无组件内步骤调用、无写入副作用：本步骤为纯输入判定，唯一可观察结果是上述 StepResult 返回。

## Requirements

### Requirement: REQ-001 三者恰有一个不为空时检查通过

来源：`docs/requirements/ST056.md`「步骤描述」第 1 条（通过分支）
系统 SHALL 统计{账户利率浮动百分点}（acctSpreadRate）、{账户利率浮动百分比}（acctPercentRate）、{账户固定利率}（acctFixedRate）三者中不为空（值非 null，数值 0 亦计为不为空）的字段数量；数量等于 1 时，检查结果 SHALL 为"通过"，步骤以成功返回：succeed=true、errorCode=null、errorMessage=null，无其他副作用。

#### Scenario: REQ-001-S01 仅账户利率浮动百分点非空→通过

- **GIVEN** acctSpreadRate=0.5000（示例值），acctPercentRate=null，acctFixedRate=null
- **WHEN** 执行 ST056 步骤
- **THEN** 不为空字段数量为 1（仅 acctSpreadRate），检查结果"通过"：succeed=true，errorCode=null，errorMessage=null

#### Scenario: REQ-001-S02 仅账户利率浮动百分比非空→通过

- **GIVEN** acctSpreadRate=null，acctPercentRate=1.25（示例值），acctFixedRate=null
- **WHEN** 执行 ST056 步骤
- **THEN** 不为空字段数量为 1（仅 acctPercentRate），检查结果"通过"：succeed=true，errorCode=null，errorMessage=null

#### Scenario: REQ-001-S03 仅账户固定利率非空→通过

- **GIVEN** acctSpreadRate=null，acctPercentRate=null，acctFixedRate=2.175（示例值）
- **WHEN** 执行 ST056 步骤
- **THEN** 不为空字段数量为 1（仅 acctFixedRate），检查结果"通过"：succeed=true，errorCode=null，errorMessage=null

#### Scenario: REQ-001-S04 唯一非空字段取值为0→仍计为恰一非空→通过

- **GIVEN** acctSpreadRate=0（BigDecimal 零值，边界示例），acctPercentRate=null，acctFixedRate=null
- **WHEN** 执行 ST056 步骤
- **THEN** 数值 0 非 null，计为不为空，不为空字段数量为 1，检查结果"通过"：succeed=true，errorCode=null，errorMessage=null

### Requirement: REQ-002 三者不为空数量不为一时返回错误码ER0032

来源：`docs/requirements/ST056.md`「步骤描述」第 1 条（否则分支）
系统 SHALL 在三者中不为空（值非 null）的字段数量不为 1（即 0、2 或 3）时，以业务失败返回[错误码]"ER0032"：succeed=false、errorCode="ER0032"、errorMessage 为工程错误码资源中 ER0032 的既有文案。

#### Scenario: REQ-002-S01 三者均为空→ER0032

#### Scenario: REQ-002-S02 百分点与百分比同时非空→ER0032

- **GIVEN** acctSpreadRate=0.5000（示例值），acctPercentRate=1.25（示例值），acctFixedRate=null
- **WHEN** 执行 ST056 步骤
- **THEN** 不为空字段数量为 2，检查不通过：succeed=false，errorCode="ER0032"

#### Scenario: REQ-002-S03 百分点与固定利率同时非空→ER0032

- **GIVEN** acctSpreadRate=0.5000（示例值），acctPercentRate=null，acctFixedRate=2.175（示例值）
- **WHEN** 执行 ST056 步骤
- **THEN** 不为空字段数量为 2，检查不通过：succeed=false，errorCode="ER0032"

#### Scenario: REQ-002-S04 百分比与固定利率同时非空→ER0032

- **GIVEN** acctSpreadRate=null，acctPercentRate=1.25（示例值），acctFixedRate=2.175（示例值）
- **WHEN** 执行 ST056 步骤
- **THEN** 不为空字段数量为 2，检查不通过：succeed=false，errorCode="ER0032"

#### Scenario: REQ-002-S05 三者均非空→ER0032

- **GIVEN** acctSpreadRate=0.5000（示例值），acctPercentRate=1.25（示例值），acctFixedRate=2.175（示例值）

- **THEN** 不为空字段数量为 3，检查不通过：succeed=false，errorCode="ER0032"

## 验收范围与明确不覆盖的事项

### 验收范围

- 2 条需求、9 个验收场景，覆盖：三种"恰一非空"通过路径（每种字段各一）、零值计入非空的边界、全空失败、两非空全部 3 种组合失败、三非空失败，即三字段空/非空组合空间（2³=8）的全覆盖加零值边界。
- 每个场景的 THEN 明确 succeed、errorCode 的取值（通过：true/null；失败：false/"ER0032"），可直接推导测试断言；errorMessage 按工程错误码资源 ER0032 既有文案断言（技术约束）。
- 验收场景是测试设计依据，不是已生成的单元测试，也不是测试执行结果。

### 明确不覆盖

- 三个利率字段取值范围、精度、正负、舍入等数值合理性校验：需求仅判空，未要求其他校验（利率类型、执行利率范围等属其他检查任务），本 Spec 不发明。
- ER0032 失败之后在交易编排中的处理（步骤短路、流程终止、回滚等）：属交易接口任务范围。
- 错误码资源 `errorcodes.properties` 的文案维护与 ER0032 以外错误码的定义。
- 三个输入字段的上游来源与赋值链路：需求「来源实体」为空，本步骤不绑定数据实体。
- 除步骤描述定义的 ER0032 业务失败外的失败处理（需求无「失败处理」章节，无技术异常约定，本步骤无数据访问与外部调用）。
- 本任务无组件内步骤调用补充说明，该约定为不适用。
