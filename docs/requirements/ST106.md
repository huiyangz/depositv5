# ST106 检查限制类型

## 步骤描述

1.获取限制类型：根据{限制类型}查询【存款限制类型表】获取[限制类型信息]

2.检查限制类型存在性：若[限制类型信息]为空，则返回检查结果为“不通过”，否则继续执行。
3.检查限制类型状态：若[限制类型信息]的$状态$为“A-有效”，则返回检查结果为“通过”，否则返回检查结果为“不通过”。

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| restraintType | com.dcits.depsit.enums.RestraintType | 必填 | 存款限制类型表（RB_RESTRAINT_TYPE） | 账户限制类型 |

## 输出
| 字段名 | 类型 | 标记 | 说明 |
|--------|------|------|------|
| checkResult | String | - | 检查结果，取值：“通过”、“不通过” |

## 相关枚举

| 枚举 | 别名 |
|------|------|
| 限制类型 | 账户限制类型、输入数据-账户限制类型 |
| 状态 | 状态 |

## 补充说明

- {账户限制类型,输入数据-账户限制类型}取值来源于代码[限制类型]，对应枚举类-类名：com.dcits.depsit.enums.RestraintType
- {状态}取值来源于代码[状态]，对应枚举类-类名：com.dcits.depsit.enums.Status

## 失败处理

本步骤无业务失败场景，失败仅由技术异常传播表达。
