# ST102 登记累计限额

## 步骤描述

1.登记累计限额：若[限额检查结果]为“未超限”，且（[限额累计金额]等于0或者[限额累计笔数]等于0），则登记限额信息，$限额场景编码$等于[限额场景编码]，$限额检查对象值$根据{限额场景编码}查询限额场景定义（RbLimitSceneDef）取得的$限额检查对象类型$赋值为{账号}或者{客户号}，$限额累计金额$等于{交易金额}，$限额累计笔数$等于1，$生效日期$等于{核心运行日期}，$失效日期$等于{核心运行日期}加{限额场景编码}查询限额控制配置（RbLimitCtrlConf）取得的$周期类型$$周期值$，其他字段的取值按照系统规则自动生成。
