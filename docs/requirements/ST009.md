# ST009 检查是否存在止付限制

## 步骤描述

1.获取账户限制信息：根据{账号}、$限制状态$等于"A-生效"查询【账户限制信息】获取[账户限制信息]（可为空、可有多条），必须包括$账户限制类型$、$限制编号$

2.获取借贷方控制标志：根据[账户限制信息]的$账户限制类型$在【限制类型表】获取$状态$等于"A-生效"的$借贷方控制标志$
3.检查是否存在止付限制：若[账户限制信息]中存在任一记录对应的[借贷方控制标志]等于"D-禁止借方"，则返回止付标志为“是”，否则返回止付标志为“否”，输出的$限制编号$、$账户限制类型$、$限制状态$取命中记录的值。
