# ST089 检查存入账户黑名单

## 步骤描述

1.获取凭证种类：根据{凭证类型}查询【凭证信息】获取其对应的$凭证种类$
2.赋值事件类型：赋值[事件类型]为“CRET”
3.执行黑名单检查规则：根据{账号}、{交易机构}、{交易类型}、[事件类型]、{服务代码}、{接口服务代码}、{接口服务类型}、{渠道类型}、[凭证种类]访问业务组件《黑名单组件》的任务《检查黑名单》的步骤《检查黑名单》，获取[执行结果]

4.检查执行结果：a.若[执行结果]为“通过”或“提醒”，则继续执行。
b.若[执行结果]为“授权”，则返回授权标志为“是”并等待授权结果后再执行后续步骤。
c.若[执行结果]为“拒绝”，则返回[错误码]“ER0057”。
