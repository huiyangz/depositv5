# ST091 检查客户限制

## 步骤描述

1.执行客户限制检查：根据{客户号}访问业务组件《检查限制组件》的任务《检查客户限制》的步骤《检查客户是否存在限制》，获取[客户限制信息]
2.检查客户限制是否存在：若[客户限制信息]等于空（未命中生效限制，三字段均为空），则检查结果为“通过”，步骤成功返回，输出字段均为空；否则将[客户限制信息]中的限制编号、账户限制类型、限制状态赋值到对应输出字段后正常返回，由调用方按输出字段处理限制。
