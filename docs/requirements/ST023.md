# ST023 检查机构币种交易权限

## 步骤描述

1.获取机构币种列表：根据{交易机构}查询【机构币种信息】获取[机构币种列表]
2.检查交易币种：若{交易币种}在[机构币种列表]范围内，则返回检查结果为“通过”，否则返回[错误码]“ER0047”。

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| tranBranch | com.dcits.depsit.enums.TranBranch | 必填 | | 交易机构号 |
| tranCcy | com.dcits.depsit.enums.Ccy | 必填 | | 交易币种 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| ccy | com.dcits.depsit.enums.Ccy | 非必填 | 机构币种表（FM_BRANCH_CCY） | 币种 |

## 相关枚举

| 枚举 | 别名 |
|------|------|
| 内部机构编号 | 交易机构号、输入数据-交易机构号 |
| 货币币种 | 交易币种、输入数据-交易币种、币种、输出数据-币种 |

## 补充说明

- {交易机构号,输入数据-交易机构号}取值来源于代码[内部机构编号]，对应枚举类-类名：com.dcits.depsit.enums.TranBranch
- {交易币种,输入数据-交易币种,币种,输出数据-币种}取值来源于代码[货币币种]，对应枚举类-类名：com.dcits.depsit.enums.Ccy
