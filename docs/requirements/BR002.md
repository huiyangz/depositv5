# BR002 计算账户利率

- 规则类型：计算类

## 规则描述

a.若{账户利率浮动百分点}不等于0，那么返回[执行利率]等于{产品利率}+{账户利率浮动百分点}；b.否则若{账户利率浮动百分比}不等于0，那么返回[执行利率]等于{产品利率}*（1+{账户利率浮动百分比}）；c.否则若{账户固定利率}不等于0，那么返回[执行利率]等于{账户固定利率}
