# ST003 检查有权机关冻结限制

## 步骤描述

1.获取账户限制信息：根据{账号}、$限制状态$等于"A-生效"查询【账户限制信息】获取[账户限制信息]，必须包括$账户限制类型$、$限制编号$
2.获取有权机关冻结标志：对[账户限制信息]中每条记录的$账户限制类型$查询【限制类型表】，获取$状态$等于"A-生效"的$有权机关冻结标志$；查得任一不为空的$有权机关冻结标志$时，将该值赋值并返回[有权机关冻结标志]，未查得时不赋值，[有权机关冻结标志]为空

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| baseAcctNo | java.lang.String | 必填 | | 账号 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| ahBuFlag | java.lang.String | 非必填 | | 有权机关冻结标志 |

## 失败处理

本步骤无业务失败场景，失败仅由技术异常传播表达。
