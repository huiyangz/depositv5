# ST080 检查交易币种

## 步骤描述

1.获取账户币种：根据{账号}查询【账户信息】获取$账户币种$；{账号}唯一确定一条【账户信息】，查无记录、多条记录或[账户币种]为空属数据异常，按技术异常处理，不继续币种比较

2.检查币种一致性：若[账户币种]不等于{交易币种}，则返回[错误码]“ER0051”，否则返回检查结果为“通过”

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| baseAcctNo | java.lang.String | 必填 | | 账号 |
| tranCcy | com.dcits.depsit.enums.Ccy | 必填 | | 交易币种 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| acctCcy | com.dcits.depsit.enums.AcctCcy | 非必填 | 对公存款账户主表（RB_BUS_ACCT） | 账户币种 |

## 相关枚举

| 枚举 | 别名 |
|------|------|
| 货币币种 | 交易币种、输入数据-交易币种 |
| 账户币种 | 账户币种、输出数据-账户币种 |

## 补充说明

- {交易币种,输入数据-交易币种}取值来源于代码[货币币种]，对应枚举类-类名：com.dcits.depsit.enums.Ccy
- {账户币种,输出数据-账户币种}取值来源于代码[账户币种]，对应枚举类-类名：com.dcits.depsit.enums.AcctCcy
