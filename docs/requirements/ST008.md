# ST008 检查是否存在现金止收限制

## 步骤描述

1.获取账户限制信息：根据{账号}、$限制状态$等于"A-生效"查询【账户限制信息】获取[账户限制信息]，必须包括$账户限制类型$、$限制编号$；[账户限制信息]为结果集，遍历全部生效限制记录，任一记录对应的限制类型满足$借贷方控制标志$等于"C-禁止贷方"且$现金标志$等于"N-不允许现金"即现金止收标志为“是”，输出的$限制编号$、$账户限制类型$取首条命中记录；无生效记录或均未命中时现金止收标志为“否”，$限制编号$、$账户限制类型$、$限制状态$、$状态$、$借贷方控制标志$、$现金标志$、$止付标志$为空

2.获取账户限制类型信息：根据[账户限制信息]中的$账户限制类型$查询【限制类型表】获取$状态$等于"A-生效"的$借贷方控制标志$、$现金标志$、$止付标志$

3.检查是否存在现金止收限制：若是限制类型对应的$借贷方控制标志$等于"C-禁止贷方"且$现金标志$等于"N-不允许现金"，则返回现金止收标志为“是”，否则返回现金止收标志为“否”。
