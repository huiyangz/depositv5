# ST016 检查是否存在现金止付限制

## 步骤描述

1.获取账户限制信息：根据{账号}、$限制状态$等于"A-生效"查询【账户限制信息】获取[账户限制信息]，必须包括$账户限制类型$、$限制编号$
2.获取账户限制类型信息：根据[账户限制信息]中的$账户限制类型$查询【限制类型表】获取$状态$等于"A-生效"的$借贷方控制标志$、$现金标志$，其中$现金标志$按单码存储，"N"表示不允许现金

3.检查是否存在现金止付限制：若[账户限制信息]中存在任一条记录，其$账户限制类型$对应的$借贷方控制标志$等于"D-禁止借方"且$现金标志$等于"N-不允许现金"，则返回现金止付标志为“是”，否则返回现金止付标志为“否”。

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| baseAcctNo | java.lang.String | 必填 | | 账号 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| cashStopFlag | java.lang.String | 非必填 | | 现金止付标志 |

## 失败处理

本步骤无业务失败场景，失败仅由技术异常传播表达。
