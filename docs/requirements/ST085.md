# ST085 检查存入客户黑名单

## 步骤描述

1.获取客户证件信息：根据 {客户号} 查询【客户证件信息】获取$客户名称$、$证件类型$、$证件号码$、$发证国家$
2.获取凭证种类：根据{凭证类型}查询【凭证信息】获取其对应的$凭证种类$
3.赋值事件类型：赋值[事件类型]为“CRET”
4.执行黑名单检查规则：根据{账号}、{客户号}、[证件类型]、[证件号码]、{交易代码}、{交易类型}、[事件类型]、{服务代码}、{接口服务代码}、{接口服务类型}、{渠道类型}、[凭证种类]访问业务组件《黑名单组件》的任务《检查黑名单》的步骤《检查黑名单》，获取[执行结果]
（按 ST105 实际契约对齐：去除目标无对应字段的 [客户名称]、[发证国家]、{交易机构}，新增必填的{交易代码}；acctBranch、blacklistCheckFlag、serviceStatus 按 ST105 已接受结论由其内部查询承载，不上送；{交易代码}的输入来源见「输入」表批注）

5.检查执行结果：a.若[执行结果]为“通过”或“提醒”，则检查结果为“通过”，以输出 dealFlow 表达（“通过”时 dealFlow 不赋值，“提醒”时为提醒处理），不另设检查结果输出字段

b.若[执行结果]为“授权”，则返回授权标志为“是”并等待授权结果后再执行后续步骤。
c.若[执行结果]为“拒绝”，则返回[错误码]“ER0003”。
