# BR004 检查交易机构和基本户开户机构互斥性

- 规则类型：断言类

## 规则描述

若{交易机构号}等于{账户开立行行号}且{账户属性}为“11002-一般存款账户”则返回执行结果为“不通过”，否则返回执行结果为“通过”。

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| tranBranch | com.dcits.depsit.enums.TranBranch | 必填 | | 交易机构号 |
| acctNatureNo | com.dcits.depsit.enums.AcctNatureNo | 必填 | | 账户属性 |
| acctBranch | com.dcits.depsit.enums.TranBranch | 必填 | | 账户开立行行号（此处指基本户的开户机构行号） |

## 相关枚举

| 枚举 | 别名 |
|------|------|
| 内部机构编号 | 交易机构号、账户开立行行号 |
| 账户属性 | 账户属性 |

- {交易机构号,交易机构号}取值来源于代码[内部机构编号]，对应枚举类-类名：com.dcits.depsit.enums.TranBranch
- {账户属性,账户属性}取值来源于代码[账户属性]，对应枚举类-类名：com.dcits.depsit.enums.AcctNatureNo
- {账户开立行行号,账户开立行行号}取值来源于代码[内部机构编号]，对应枚举类-类名：com.dcits.depsit.enums.TranBranch
