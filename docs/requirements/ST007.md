# ST007 检查质押类限制

## 步骤描述

1.获取账户限制信息：根据{账号}、$限制状态$等于"A-生效"查询【账户限制信息】获取[账户限制信息]，生效记录可能有多条，逐条执行步骤2；无生效记录时步骤正常返回，输出字段均为空；[账户限制信息]必须包括$账户限制类型$、$限制编号$

2.获取质押标志：根据[账户限制信息]中的$账户限制类型$查询【限制类型表】获取$状态$等于"A-生效"的$质押标志$赋值并返回[质押标志]
